# Mockup de modernização

`dashboard-modernizado-conceito.png` é uma proposta visual, não uma tela implementada.

Foi gerado com a ferramenta de imagens integrada, usando o seguinte prompt:

> Use case: ui-mockup. Asset type: concept image for a technical documentation report. Create a polished desktop web dashboard concept for modernizing a Brazilian nonprofit student rewards system called META; show reward coins, recent transactions, quick actions and accessible navigation. Full browser viewport, high-fidelity contemporary SaaS UI, left sidebar, deep navy with orange and teal accents, Portuguese interface, fictional data, no copied brand logo and no watermark. Include: “META”, “Visão geral”, “Saldo de honras”, “Movimentações recentes”, “Alunos”, “Adicionar honras” and “Utilizar honras”.

Antes de implementação, a identidade visual, textos, acessibilidade, responsividade e regras de exposição de indicadores precisam ser validados com o Projeto META.
