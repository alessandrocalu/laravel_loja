# Capturas das telas atuais

Estas imagens foram reconstruídas a partir de `resources/views/app.blade.php`, `home.blade.php`, `auth/*`, `admin/users/*` e dos estilos em `public/css/`. Não houve acesso ao banco remoto nem uso de dados pessoais.

Os nomes, e-mails, telefones, matrículas, saldos e datas são fictícios. O reCAPTCHA é apenas uma representação visual. A captura de “Adicionar honra” contém um aviso documental azul que não existe na aplicação.

O HTML usado para renderização está em `../../source/screens.html`.
